# TJ-ChaseVoice
猫和老鼠手游语音数据集

## 说明
1. 本数据集在Eternity-Ixy的[原数据集](https://github.com/Eternity-Ixy/TJ-ChaseVoice)的基础上进行了标注，标注文件位于每个角色文件夹的 `text.txt`

2. 标注格式：

    文件名|标注内容

注：标注内容按文件名的名称升序排列

中文和英语为人工标注，其余语言使用Fast Whisper large-v3模型识别

3. 对比原数据的其它变动：
    
    对同一角色的不同配音做了较严格区分，请自行判断是否混合

    将无实义的音频放入角色文件夹下的 `mood` 文件夹中，唱歌的音频则放入 `sing` 文件夹中

    将add系列文件重命名为extra
